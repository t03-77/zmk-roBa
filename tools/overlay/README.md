# roBa キー配置オーバーレイ（Windows）

画面の下に roBa のキー配置を半透明で表示し続けるアプリです。

- **レイヤーに連動**：BS長押しでナビ、ボールを動かしてマウス…と、今効いているレイヤーの配置に自動で切り替わります
- **押したキーが光る**：どの位置のキーを押したかが分かります。いま押さえているレイヤーキーは青く表示
- **キーマップを直接読む**：`config/roBa.keymap` を書き換えると表示も自動で追従（アプリの修正は不要）
- **操作の邪魔をしない**：常に最前面・クリックは下のウィンドウへ素通り・タスクバーにも出ません

## 使い方

1. Python 3.10 以上を入れる（python.org の公式版。追加ライブラリは不要）
2. `start_overlay.bat` をダブルクリック

PC起動時に自動で出したいときは、`Win + R` → `shell:startup` で開いたフォルダに `start_overlay.bat` のショートカットを置きます。

## ショートカット（Ctrl + Alt + Shift + …）

エディタや Blender の Ctrl+Alt 系ショートカットとぶつからないよう、Shift も一緒に押します。

| キー | 動作 |
|---|---|
| K | 表示／非表示 |
| H | 「レイヤー切替中だけ表示」モード（普段は隠れ、BS長押し等の間だけ出る。ボールを触っただけでは出ない） |
| M | 移動・調整モード：ドラッグで移動、矢印キーだけで ↑↓ 濃さ・←→ 大きさ。Esc かもう一度 M で固定 |
| L | 表示レイヤーを手動で切替（レイヤー通知の無いファームのとき） |
| P | 練習アプリを開く |
| Q | 終了 |

**練習の声かけ**：1日1回、オーバーレイを起動して10分たつと「今日の練習（5分）」と90秒だけ表示されます（隠していても出ます）。Ctrl+Alt+Shift+P で練習アプリが開きます。いらなければ `roba_overlay_settings.json` の `"practice_reminder"` を `false` に。

うまく出ないときは、同じフォルダの `roba_overlay.log` に理由が書かれています。

位置・濃さ・大きさは `roba_overlay_settings.json` に保存され、次回も同じ状態で起動します。

## レイヤー連動のしくみ

レイヤーを切り替えてもPCには何も届かないため、ファームウェア（右手）が**レイヤーが変わるたびに F13〜F20 を1回送る**ようにしてあります（`roBa_R.conf` の `CONFIG_ROBA_LAYER_SIGNAL=y`）。アプリはこのキーを受け取って表示を切り替え、**握りつぶすので他のアプリには届きません**。

- アプリを起動していないときは F13〜F20 がそのままPCに届きます。普通のアプリは反応しませんが、気になる場合は `CONFIG_ROBA_LAYER_SIGNAL=n` にしてビルドし直してください（そのときは Ctrl+Alt+Shift+L で手動切替）
- ZMK Studio でレイヤーの並びを変えると、アプリ（`roBa.keymap` を読んでいる）とずれます。Studio ではキーの中身だけ変え、レイヤー構成は keymap ファイルで変えてください
- 管理者権限で動いているウィンドウ（タスクマネージャー等）を操作中は、Windowsの仕様でアプリにキーが届かず表示が止まります

## 表示の見方

- 薄い文字 … そのレイヤーでは素通り（下のレイヤーのキーがそのまま効く）
- 黄色の枠 … 長押しで別の働きをするキー（下に小さく説明）
- 青の枠 … レイヤー切替キー／緑の枠 … マウス操作／赤の枠 … Bluetooth等のシステム操作
