roBa キーマップ

ZMK v0.343キー + トラックボールWindows / 日本語配列のままQWERTY
L0 基本L1 記号L2 数字L3 ナビ・FL4 マウスL5 スクロールL6 システムL7 精密ショートカットシール用ボール操作

覚えることは3つだけ

  • 文字の並びと Ctrl・Win・Alt の位置は、いま使っているキーボードと同じです。
  • Enter を押さえると記号、Space を押さえると数字とFキー、BS を押さえると矢印。
  • ボールを動かすと J・K・L がクリックになり、止めれば元の文字に戻ります。

PC の設定はそのまま（日本語配列）で使えます。記号はキーボード側で日本語配列向けに直してあります。

L0

基本 Base

いつも

文字の並びは普段のキーボードと同じ。左下は普段と同じ Ctrl・Win・Alt の順で、Ctrl+C は左小指＋中指。Ctrl+Z / Ctrl+A のように左小指が重なるときは、右下の Del を長押しすると Ctrl になります。英数・かなは押すだけで IME がオフ・オンになり、今どちらかを気にしなくて済みます。

L1

記号 Symbol

Enter を長押し

上の段は、普段のキーボードで Shift を押しながら数字を押したときと同じ並び（Q が ! 、I が ( ）。- と : は普段どおり Shift を押すと = と * になります。

L2

数字 Number

Space を長押し

上の段が数字の段、その真下が F キー（F1 は 1 の下）。Space を押さえたまま左手で 1〜5、右手で 6〜0。

L3

ナビ・F Nav

BS を長押し

左手の E S D F が ↑←↓→。Home / End はその両側。単語選択は Ctrl+Shift+←/→ を1キーで。スクロール固定はもう一度押すか、かなを長押しして離すと解除。

L4

マウス Mouse

ボールを動かすと自動（止めて0.6秒で戻る）

J・K・L が左・中・右クリック（roBa の初期配置と同じ）。打鍵直後 0.2 秒はボールに触れても入らないので、タイプ中の誤クリックを防ぎます。ほかのキーを押すと即解除されて文字が打てます。ボールを止めて 0.6 秒以内に J・K・L を打つとクリックになる点だけ注意。

L5

スクロール Scroll

かな を長押し／ナビの Tab 位置で固定

ボールがホイールになります。奥へ転がすと上へスクロール。横スクロールは弱めにしてあります。キーは全部素通りなので、固定中も普通に文字が打てます。

L6

システム System

Space と Enter を両方長押し

BT1〜5 で接続先を切替。書込モード（ブートローダー）は左右それぞれ、その側のキーで入ります。

L7

精密 Snipe

マウス中に ; を長押し

カーソルが 1/4 の速さに。Blender の頂点選択や DAW の細かい編集に。

シール用の統合図

1キーに最大4つ
中央 文字（普段と同じ）右上 記号（Enter長押し）右下 数字（Space長押し）左下 ナビ・F（BS長押し）

文字は普段と同じなので、シールは右上の記号だけで足ります。数字は上の段にそのまま並び、Fキーはその真下、矢印は左手の E S D F なので、書かなくても辿れます。マウス・スクロール・システムはシール不要です。

よく使うショートカットの押し方

操作押し方

Ctrl+Z / A / Q（左小指が重なるもの）右下の Del を長押し（右小指）＋ 文字
Shift+文字英数を長押し（左親指）＋ 文字
Ctrl+Shift+Z（やり直し）右下 Del 長押し ＋ 英数長押し ＋ Z
Alt+Tab / Ctrl+Tab左下の Alt か Ctrl ＋ G の右の Tab
Ctrl+Space（補完・Blender の画面最大化）Ctrl ＋ Space をすばやく押す

Blender の 1 / 2 / 3（頂点・辺・面）Space を押さえて Q / W / E

トラックボールの使い方

やりたいこと操作
クリックボールを動かすとマウスレイヤーに入る → J・K・L が左・中・右クリック
スクロール左親指で「かな」を長押ししながらボール（カーソルは動かない）
スクロールしっぱなしBS長押し＋Tab の位置で固定。もう一度同じ操作か、かなを長押しして離すと解除
細かい位置合わせマウス中に ; を押さえたまま操作 → 1/4 の速さ
Ctrl+クリック、Shift+中ドラッグCtrl / 英数(Shift) を押してもマウスレイヤーは切れないので、そのままクリック・ドラッグ
Blender でクリック → TabTab と Esc もマウスレイヤーを切らないので、クリック・Tab・クリックが続けてできる
ズーム（Ctrl+ホイール）Ctrl を押しながら「かな」長押し＋ボール
エンコーダー（付いている場合）普段はホイール、ナビ中はタブ切替、システム中は音量

書き込み手順（初回）

  1. 右手をUSBでつなぎ、XIAO のリセットを素早く2回 → XIAO-SENSE ドライブに settings_reset をコピー。左手も同じ
  2. 右手に roBa_R、左手に roBa_L を同じ方法でコピー
  3. Windows の Bluetooth 設定で古い roBa を削除して、もう一度ペアリング
  4. PC の設定変更は不要。英数・かなは Microsoft IME でそのまま効きます（Google 日本語入力の場合は動作を確認）

2回目以降、配置だけ変えたときは右手に roBa_R を書くだけです。この図は tools/make_keymap_sheet.py でキーマップから作り直せます。
